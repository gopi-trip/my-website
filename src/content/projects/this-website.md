A personal site built to be lived in rather than shown off. Content lives in
plain Markdown and YAML; pages are static HTML with almost no JavaScript.

## Features

- A [wiki](/wiki/) with `[[wikilinks]]`, backlinks, growth stages and instant search.
- A [microblog](/micro/), a [/now page](/now/) with an archive, and a [bookshelf](/bookshelf/) driven by a single YAML file.
- One RSS feed for everything, a sitemap, light and dark themes.
- Pixel icons defined as text grids and rendered to crisp SVG.

The longer story is in [Building a website to live in](/writings/building-this-site/).
